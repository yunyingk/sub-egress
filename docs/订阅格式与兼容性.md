# 订阅格式与兼容性

本页记录 2026-11-10 的调研和客户端验证结果，避免将不同层次的格式当成一个统一标准。对于正在开发的行为，以上线版本和实际测试结果为准。

## 格式边界

- **订阅传输**：sub-egress 使用 HTTP 返回订阅内容；`target=clash`、`target=sing-box` 和 `target=base64` 是本项目的格式选择参数，并非各客户端共同规定的版本协商标准。
- **Mihomo 配置**：Clash/Mihomo 目标输出 YAML，其字段应遵循 [Mihomo 官方配置文档](https://wiki.metacubex.one/en/config/)。
- **Sing-box 配置**：Sing-box 目标输出完整 JSON，其字段应遵循 [Sing-box 配置文档](https://sing-box.sagernet.org/configuration/)和目标内核版本的[迁移指南](https://sing-box.sagernet.org/migration/)。这不是 Mihomo YAML 的另一种序列化。
- **Base64 链接列表**：Base64 是编码，解码后的每行是节点 URI；支持哪些 URI、扩展参数及是否能够连接，取决于导入客户端。
- **AnyTLS**：Sing-box 从 1.12.0 起支持 [AnyTLS 出站](https://sing-box.sagernet.org/configuration/outbound/anytls/)；参考实现提供 [AnyTLS URI 格式](https://github.com/anytls/anytls-go/blob/main/docs/uri_scheme.md)。基本 URI 包含地址、密码、SNI、证书验证和名称；其他参数属于客户端扩展，不保证所有客户端都能识别。

## 目前发现的兼容问题

对 v0.5.1 使用的完整 Sing-box 配置和新增 AnyTLS 测试节点，以官方发布的客户端执行 `sing-box check`：

- 1.12.0：默认拒绝旧特殊出站；启用其临时兼容开关后，因 GeoIP 旧数据库格式已移除仍无法加载。
- 1.14.4：直接因旧 DNS 服务器格式被移除而无法加载。
- 将新生成的 AnyTLS 出站单独放入最小配置后，1.14.4 的 `sing-box check` 通过。该结果只验证该节点配置的结构，不证明现有完整配置可用，也不证明连接成功。

上游迁移指南说明了 [DNS 服务器格式迁移](https://sing-box.sagernet.org/migration/#migrate-to-new-dns-server-formats)、[特殊出站迁移](https://sing-box.sagernet.org/migration/#migrate-legacy-special-outbounds-to-rule-actions)和 [GeoIP/Geosite 迁移到规则集](https://sing-box.sagernet.org/migration/#migrate-geoip-to-rule-sets)。完整配置迁移必须核对规则顺序、DNS 路由、规则集获取与目标客户端版本，不应只删除报错字段。

## 版本参数

目前接口**不处理**客户端版本参数。URL 中自行添加的 `version` 不会让服务自动适配客户端，也没有证据表明它是 Clash、Sing-box 客户端通用的标准参数。若引入版本选择，需要明确参数属于 sub-egress 的约定、校验支持的范围，并用对应版本客户端验证生成配置；不支持的版本应明确报错。

订阅令牌属于敏感凭据，示例、日志和问题报告不得包含真实订阅 URL 或节点密码。

## 新版配置验证

正在开发的一套新版 Sing-box 配置使用 DNS 新格式、规则动作和远程规则集；订阅 URL 不增加版本参数。使用官方内核验证：

- 1.12.0 和 1.14.4：完整测试配置通过 `check`，并使用测试代理实际启动；从线上数据生成的配置在排除不支持的 XHTTP 节点和补齐 Reality uTLS 后也通过两版检查。
- 1.14.4：使用一个实际 AnyTLS 节点完成 HTTPS 转发测试。1.13 客户端下载超时，尚未验证。
- 首次启动需经当前 `PROXY` 出站从 jsDelivr 下载 SagerNet 的 GeoIP/Geosite 规则集；无可用代理或规则集不可达时可能无法启动，已有缓存可减轻依赖。
- `download_detour` 在 1.14 已弃用，计划在 1.16 移除；在支持 1.12 的同时需要它指定规则下载出站。未来升级时应按官方迁移到 HTTP 客户端配置。
- 官方 Sing-box 的 V2Ray Transport 未列出 XHTTP；此类节点不输出到 Sing-box 或当前 Base64 生成器，Clash 输出不受此限制。参考 [Sing-box 传输配置](https://sing-box.sagernet.org/configuration/shared/v2ray-transport/)。
